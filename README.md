# 🎓 Student Performance Analyzer

A Python and Streamlit web application for analyzing student performance and class statistics.

## 📌 About the Project

Student Performance Analyzer allows users to enter student names and scores and automatically generates an overview of class performance.

This project was developed as part of my Python learning journey and demonstrates the practical use of Python fundamentals in a simple interactive application.

## ✨ Features

- Add student names and scores
- Automatically classify student performance
- Calculate the class average
- Calculate the pass rate
- Identify the highest and lowest scores
- Count passed and failed students
- Display student records in a table
- Visualize student scores using a bar chart
- Clear all student records

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- Git & GitHub

## 📊 Performance Categories

| Score | Result |
|------|------|
| 90–100 | Excellent |
| 75–89 | Very Good |
| 60–74 | Passed |
| Below 60 | Failed |

## 🚀 Run the Project

Install the required libraries:

pip install -r requirements.txt

Then run the application:

streamlit run app.py
